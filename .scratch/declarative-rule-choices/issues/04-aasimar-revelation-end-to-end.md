# 04: Aasimar revelation, end to end

**Blocked by:** 03 — Rule Choice storage and migration.

**Status:** ready-for-agent

- [ ] A player picks an ancestry offering a Rule Choice in the builder, using the existing generic choice picker — no new component.
- [ ] Every option is offered with its full rules text readable without leaving the sheet.
- [ ] A counter shows how many picks remain, a completed pick locks the remaining options, and an owed pick can be changed before completion.
- [ ] The choice is absent below its unlock level and present once the character reaches it.
- [ ] The chosen option's effect appears on the resolved feature list, beneath the trait that granted it, with that trait's own prose intact.
- [ ] Options wrap rather than run off the edge on a narrow screen.
- [ ] The DMG and VGM Aasimars behave exactly as they do today.
