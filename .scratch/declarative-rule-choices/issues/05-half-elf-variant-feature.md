# 05: Half-Elf variant feature

**Blocked by:** 04 — Aasimar revelation end-to-end.

**Status:** ready-for-agent

- [ ] Each SCAG descent offers exactly its own option set, drawn from the catalog rather than hand-listed.
- [ ] Skill Versatility is selectable as a variant feature.
- [ ] Choosing Skill Versatility yields a two-skill choice among all skills; choosing a descent feature yields none.
- [ ] The chosen feature's text appears on the resolved feature list.
- [ ] Skill Versatility does not appear on the resolved feature list when a different feature was chosen — suppression is driven by the catalog's overwrite marker, not by a per-ancestry special case.
- [ ] A Variant Half-Elf with no recorded choice is flagged for review, since one saved before this change never had the option available.
- [ ] A base (non-variant) Half-Elf still gets Skill Versatility and no descent choice.
- [ ] Ancestry ability score increases are unchanged.
