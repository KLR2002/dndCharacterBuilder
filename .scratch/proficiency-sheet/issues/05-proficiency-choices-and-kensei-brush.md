# 05: Proficiency Choices and the Kensei brush

**What to build:** Proficiency Choices (a rule offering a pool) can be picked in the Class & Subclass Choices card, shown as "Picked N / M", and saved per grant id. A Way of the Kensei monk chooses calligrapher's supplies or painter's supplies, and the pick appears on the sheet. Old saved choice buckets (race, background and class tools and languages) keep being read and are never rewritten. A pick whose grant no longer applies is released by the reconciler with a notice. Pickers hide what the character already has; a fixed grant that duplicates is kept once.

## Design notes (main session)

- **Pick store.** One new optional character field maps a grant id to the picked names (tools and languages only in this ticket; the type leaves room for the other categories). Old `chosenTools` and `chosenLanguages` buckets stay and are read by the structured readers; never rewrite or migrate them.
- **Sheet.** For every choice grant of category tools or languages on a feature the character currently has (reuse the granted-features pass), the sheet adds the saved picks that are still valid for the grant's pool (a names pool, or `any` meaning every known tool or language) and not duplicates. A pick for a grant the character no longer has contributes nothing, but stays stored.
- **UI.** Each Proficiency Choice appears in the existing Class & Subclass Choices card as a picker with "Picked N / M", using the existing picker components; the pool hides names the character already holds from any other source (its own picks stay selectable and deselectable). A choice offering `any` shows the known tool or language list. No explanatory text.
- **Reconciler.** A pick is released, with a `needsReview` notice, only when the character no longer holds the owner of its grant (class or subclass dropped, level below the feature's level, feat removed) and the Compendium can tell: with no catalog data the pick is kept (saved picks are never thrown away for a missing catalog). Reconciling a valid character returns it unchanged.
- **Id guard.** A recorder-generated list of every grant id in the tracked class and feat data (regenerated by an environment variable, never by hand); a test fails if any recorded id disappears or changes, and allows additions.
- **Kensei.** The Way of the Kensei brush choice (calligrapher's or painter's supplies) is the acceptance example, tested end to end through the sheet with the integrated test compendium. Other choice grants of tools and languages in the data work through the same mechanism.
