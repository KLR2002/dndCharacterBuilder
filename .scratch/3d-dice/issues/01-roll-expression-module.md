# 01: Roll Expression module

**What to build:** A pure module `src/rules/rollExpression.ts` that turns the text a player types into Rolls, lifted from the `m-expr` script of the prototype (`git show prototype/3d-dice:.scratch/3d-dice/prototype-dice.html`), reshaped to this repo's style (`RandomSource` from `src/rules/dice.ts`, `.ts` import extensions, no DOM). It exports: `parseRollExpression(text)` returning `{ ok: true, rolls }` or `{ ok: false, message, position }` (one entry per Roll, the count before a function already expanded); `planRollDice(rolls)` (the sides of every die over all Rolls, in the order `evaluateRolls` asks the random source); `evaluateRolls(rolls, random)` returning, per Roll, `{ text, roll }` where `text` is the canonical text of that Roll (`a(d20+5,d20+2)`, `d4+a(d20)`) and `roll` is a `Roll` from `dice.ts`; the limits `MAX_ROLLS_PER_EXPRESSION = 10`, `MAX_DICE_PER_EXPRESSION = 100`, `MAX_SIDES = 1000`; and the text-editing helpers behind the tray controls: `addDieToExpression(text, sides)`, `expressionModifier(text)`, `bumpExpressionModifier(text, delta)`, `expressionD20Mode(text)` (null, or "disadvantage" / "none" / "advantage") and `setExpressionD20Mode(text, mode)`. Grammar and rules are in `spec.md` (Decisions). `RolledDie` in `dice.ts` gains an optional `subtracted?: true`, set for dice that follow a `-`; `Roll.total` counts a kept subtracted die negatively. Error messages are one short sentence each. `parseDicePool` and `rollDicePool` stay for the damage pools of roll badges.
