# 06: Draw a solid die with react-native-svg

**What to build:** A pure projection `src/rules/diceProjection.ts` and a component `src/components/dice/SolidDie.tsx`, lifted from `drawDie` in the prototype. `projectDie(geo, quaternion, size, ...)` returns what to draw for one die: every face in geometry order (a face turned away is marked not visible; the visible faces of a convex solid never overlap, so no sorting is needed and a fixed element order per die is safe to animate), each with its screen polygon as a `points` string, a fill from a fixed light, and its labels as SVG transform strings of 2D affine matrices (text) or pips (d6), all from plain numbers so it can run inside a Reanimated worklet (functions marked `'worklet'`, no closures over non-serialisable values; the directive is a no-op for the Node tests). `SolidDie` takes `{ geo, quaternion, size, accent, dropped }` where `quaternion` is a Reanimated `SharedValue<Quat>` (a static caller wraps its pose in `useSharedValue`), computes one projection per frame with `useDerivedValue`, and draws it with `Svg` and one small `FaceView` per face index (a constant number of elements per die kind), each driven by `useAnimatedProps` on `Polygon`, `Text` (with the matrix string as its transform) and, for the d6, a `G` holding exactly the face's pips as `Circle`s; a hidden face has opacity 0; the body takes the accent's `primary`, the numerals its `text`, a dropped die turns grey and muted. The component is lazy-loaded behind the existing `DiceRenderer` slot like the current renderer, so nothing of it loads while the animation is Off. It is not mounted anywhere yet; the next ticket uses it. If an SVG `Text` matrix transform does not render on Android, wrap the label in a `G` with the transform and say so in the report.
