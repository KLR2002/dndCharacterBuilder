## Verification
Verify all changes: `npm run check:all`. UI changes also need `npm run layout:check` (needs `npx expo start --web --port 8099` running and a one-time `npx playwright install chromium`); layout rules are in `CODING_STANDARDS.md` section 7.

## Compendium Architecture
- SRD baseline: `src/data/*.json` (pruned via `node scripts/prune-to-srd.mjs`). Do not overwrite with expansion content.
- Integrated compendium: generated by `dnd5eToolsScrap/` and cached via `src/services/compendiumStorage.ts`.

## Navigation
- Progression & spells: `src/rules/` (`spellcasting.ts`, `ruleChoices.ts`, `characterEvaluation.ts`).
- Combat economy & actions: `src/rules/` (`attacks.ts`, `ac.ts`, `tacticalActions.ts`).
- In-app scraper & cache: `src/services/scraper/runner.ts`, `src/services/compendiumStorage.ts`.
- Character test fixtures: `makeChar()` in `checks/testUtils.ts`.
- Architecture decisions: `docs/adr/`.
