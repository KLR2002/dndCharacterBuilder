## Verification
Always verify changes using `npm run check:all` (runs `npm test`, `npm run typecheck`, and `expo lint`).

## Data Pipeline
Catalog files in `src/data/*.json` are generated by `dnd5eToolsScrap/`. Do not edit `src/data/*.json` directly.
To update data: edit `dnd5eToolsScrap/src/scrapers/`, re-run `npm run scrape:items` (or `scrape:spells`, `scrape:books`, `scrape:all`), and sync output to `src/data/`.
